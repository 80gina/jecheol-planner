### ③ KAMIS 키가 나왔으면 `.env` 에 넣기

메모장 대신 명령어로 넣습니다. **따옴표 안의 값만 실제 키로 바꾸세요.**

```powershell
(Get-Content .env) -replace '^KAMIS_CERT_KEY=.*', 'KAMIS_CERT_KEY=여기에실제키' | Set-Content .env
```

```powershell
(Get-Content .env) -replace '^KAMIS_CERT_ID=.*', 'KAMIS_CERT_ID=신청때쓴이메일' | Set-Content .env
```

확인 (길이만 셉니다 — 키가 화면에 안 뜹니다):

```powershell
Select-String -Path .env -Pattern "^KAMIS_CERT_KEY=" | ForEach-Object { $_.Line.Length }
```

> `27` 이 나오면 아직 자리표시자입니다. 그보다 크면 키가 들어간 것입니다.

1. **`collect` 는 시연 중에 돌리지 않는다.** 몇 분 걸리고 API 상태에 따라 실패한다.
2. **`.env` 는 절대 GitHub 에 올리지 않는다.** `.gitignore` 가 막고 있지만 확인 습관을 들일 것.
3. **오류가 나면 그 화면을 먼저 찍는다.** 결과보고서 XI장 오류 이력에 쓸 재료다.
