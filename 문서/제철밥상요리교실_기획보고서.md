## Ⅰ. 기획 개요

### 1. 왜 또 하나의 요리교실인가

평생학습센터 요리교실은 흔하다. 대부분 **레시피를 따라 만들고 먹고 끝난다.**
수강생은 그날 배운 음식을 집에서 한 번 해보고, 그것으로 관계가 끝난다.

이 과정은 다르게 설계했다. **음식을 만드는 시간을 셋으로 나눈다.**

| 층 | 무엇을 하나 | 남는 것 |
|---|---|---|
| **손** | 제철 재료로 요리한다 | 기술 — 집에서 다시 할 수 있다 |
| **이야기** | 그 재료에 얽힌 설화·역사·철학을 듣는다 | 기억 — 남에게 말할 수 있다 |
| **눈** | 그 재료가 어떻게 자라는지 본다 (생태해설) | 관점 — 시장에서 다르게 보인다 |

**세 번째 층이 이 과정의 핵심이다.**
무화과를 먹어본 사람은 많지만, **무화과에 왜 꽃이 안 보이는지** 아는 사람은 드물다.
그것을 알고 나면 무화과는 더 이상 그냥 과일이 아니다.

### 2. 기획 배경

| 배경 | 내용 |
|---|---|
| **식생활 변화** | 사철 아무거나 구할 수 있게 되면서 '제철'의 감각이 사라졌다. 절기와 음식의 연결고리가 끊겼다 |
| **지역 자원** | 창원·경남은 남해 수산물과 내륙 밭작물이 함께 나는 드문 지역이다. 계절 재료가 풍부하다 |
| **평생학습 수요** | 단순 기능 습득을 넘어 '의미 있는 배움'에 대한 요구가 커지고 있다 |
| **해설 인력** | 숲해설·문화해설 역량을 요리 프로그램에 결합한 사례가 드물다 — **차별점이자 진입 장벽** |

### 3. 다른 요리교실과의 차이

| | 일반 요리교실 | **본 과정** |
|---|---|---|
| 재료 선정 | 강사 취향·조달 편의 | **제철성 + 실제 시세 데이터 근거** |
| 수업 구성 | 시연 → 실습 → 시식 | 이야기 → 관찰 → 실습 → 시식 → 잇기 |
| 해설 | 조리법 설명 | **문화해설 + 생태해설** |
| 남는 것 | 레시피 한 장 | 레시피 + 이야기 + 계절 감각 |
| 확장 | 없음 | 숲 체험·시장 탐방·기록물 제작으로 연결 |

### 4. 재료 선정의 근거 — 데이터를 쓴다

재료를 감으로 고르지 않는다. **KAMIS 농산물유통정보의 2년치 일별 소매가격**과
**기상청 지상관측 일자료(창원)** 를 분석해 품목별 월별 계절 지수를 산출하고,
그 결과를 회차 배치의 근거로 삼는다.

> **계절 지수** = (그 달 평균가격 ÷ 연평균가격) × 100
> 예: 시금치 12월 지수 140 → 그 달은 평소보다 40% 비싸다

| 데이터가 답해주는 것 | 기획에 쓰는 법 |
|---|---|
| 품목별 가장 싼 달·비싼 달 | 회차별 주재료 배치 |
| 품목별 가격 변동폭 | 예산이 흔들리지 않는 '기준 재료' 선정 |
| 기온과 가격의 관계 | 생태해설의 근거 ("추우면 왜 비싼가") |

> 📊 **부록 A**에 품목별 계절 지수표를 수록한다. 지수는 매년 갱신해 다음 기수에 반영한다.

## Ⅱ. 설계 원리

### 1. 한 회차의 3층 구조

```
   ┌─────────────────────────────────────────────┐
   │  여는 이야기 (15분)                          │
   │   설화 · 속담 · 역사 · 철학 · 예술            │
   │   "왜 우리 조상은 이것을 먹었나"               │
   ├─────────────────────────────────────────────┤
   │  재료 관찰 · 생태해설 (15분)                  │
   │   실물을 만지며 · 어떻게 자라나 · 왜 지금인가   │
   │   "이 재료는 어떤 전략으로 살아남았나"          │
   ├─────────────────────────────────────────────┤
   │  조리 실습 (45~60분)                         │
   │   시연 → 조별 실습                            │
   ├─────────────────────────────────────────────┤
   │  시식 · 잇기 (20분)                          │
   │   함께 먹으며 · 다음 회차 예고 · 집에서 할 일   │
   └─────────────────────────────────────────────┘
```

### 2. 이야기 선정 원칙 4가지

| # | 원칙 | 왜 |
|:-:|---|---|
| 1 | **재료에서 출발한다** | 요리에 억지로 갖다 붙인 이야기는 티가 난다. 재료 자체에 있는 이야기만 쓴다 |
| 2 | **한 회차에 하나** | 설화·역사·철학을 다 넣으면 아무것도 안 남는다. 축이 되는 이야기 하나 + 곁가지 |
| 3 | **손이 움직이는 동안 말한다** | 앉혀놓고 강의하지 않는다. 다듬고 썰면서 듣는다 |
| 4 | **확인 가능한 것과 전해오는 것을 구분한다** | "유네스코 등재 사실"과 "이런 이야기가 전해온다"를 섞지 않는다 |

### 3. 생태해설 선정 원칙

**음식이 되기 전의 모습**을 다룬다. 그리고 **먹는 부위가 식물의 어느 기관인지**를 반드시 짚는다.

| 먹는 부위 | 사례 | 해설 포인트 |
|---|---|---|
| 뿌리 | 무, 당근, 고구마 | 저장기관 — 겨울을 나려고 모아둔 것을 우리가 먹는다 |
| 줄기 | 감자, 대파, 두릅 | 감자는 뿌리가 아니라 **덩이줄기**다 |
| 잎 | 배추, 시금치, 쑥 | 광합성 공장 — 그래서 계절과 일조에 민감하다 |
| 꽃 | 브로콜리, 무화과 | 브로콜리는 **꽃봉오리**, 무화과는 **꽃이 안으로 들어간 것** |
| 열매·씨 | 오이, 콩, 팥 | 다음 세대를 위한 도시락 |

> 💡 **이 표 한 장이 수업의 관점을 바꾼다.** "감자는 뿌리가 아니다"를 알게 된 순간부터
> 수강생은 재료를 '식재료'가 아니라 '식물의 일부'로 보기 시작한다.

### 🌱 모듈 1 — 이른 봄, 언 땅을 뚫고 (냉이·달래)

| | |
|---|---|
| **시기** | 2월 말 ~ 3월 |
| **메뉴** | 냉이된장국 · 달래장 · 봄나물 비빔밥 |
| **난이도** | ⭐ 쉬움 · 40분 |

**추천 이유 (재료)**
겨울을 땅속에서 난 뿌리채소는 **당분을 모아둔 상태**다. 1년 중 가장 향이 진한 시기이며,
노지 출하가 시작되는 시점이라 값도 안정적이다.

**🏛 문화해설 — 입춘 오신반(五辛盤)**
조선 시대 입춘에는 다섯 가지 매운맛 나는 봄나물을 임금께 올렸다. 궁중에서 시작해
민간으로 퍼진 풍습이다. 겨우내 부족했던 비타민과 미네랄을 봄나물로 보충한
**생활의 지혜가 의례가 된 사례**다.

**🌿 생태해설 — 로제트, 땅에 납작 엎드리는 전략**
냉이는 겨울을 **로제트(rosette)** 형태로 난다. 잎을 방석처럼 땅에 붙여 펼치는 모양이다.

- 왜? 지면 가까이가 바람이 약하고 **땅의 복사열**을 받는다
- 왜? 납작하면 위로 자란 다른 풀에 가리지 않고 겨울 햇빛을 독차지한다
- **관찰 활동**: 뿌리째 가져와 잎이 사방으로 퍼진 모양을 직접 보게 한다

> "이 모양이 겨울을 견딘 자세입니다. 우리가 먹는 건 그 겨울을 버틴 뿌리예요."

**💭 이야기 한 줄**
달래의 옛 이름은 '소산(小蒜)' — 작은 마늘이다. 단군신화의 마늘이 실제로는
달래나 산마늘이었을 것이라는 견해도 있다. **확정된 사실은 아니지만 흥미로운 논점**이다.

**기대효과**: 봄 나물 3종을 구분할 수 있다 · 로제트 개념을 설명할 수 있다 · 절기와 음식의 연결을 이해한다

### 🌿 모듈 2 — 쑥, 가장 오래된 나물 (쑥)

| | |
|---|---|
| **시기** | 3월 ~ 4월 초 |
| **메뉴** | 쑥국 · 쑥버무리 · 쑥개떡 |
| **난이도** | ⭐⭐ 보통 · 50분 |

**추천 이유**
채취 시기가 짧다. **4월 중순이 지나면 억세져 못 먹는다.** "지금이 아니면 안 된다"는
제철의 감각을 가장 직접적으로 가르칠 수 있는 재료다.

**📖 설화 — 단군신화의 쑥**
곰이 쑥과 마늘을 먹고 사람이 되었다는 이야기. 여기서 쑥은 **인내와 변화의 상징**이다.

> 왜 하필 쑥이었을까. 쑥은 척박한 땅에서도 자라고, 불에 타도 뿌리에서 다시 올라온다.
> 가장 흔하고 가장 질긴 풀이다. **신화는 그 특성을 알고 고른 것일 가능성이 있다.**

**🌿 생태해설 — 국화과의 성공 전략**
쑥은 국화과다. 국화과는 지구상 식물 중 가장 번성한 무리에 속한다.

- **작은 꽃 여러 개를 모아 큰 꽃처럼 보이게 하는 구조** (두상화서)
- 씨앗에 갓털을 달아 바람으로 퍼뜨린다
- 뿌리줄기로도 번지므로 한 번 자리 잡으면 잘 사라지지 않는다
- **관찰 활동**: 쑥 뒷면의 흰 솜털을 확대경으로 본다 → 수분 증발을 줄이는 구조

**🎨 예술 연결**
단오에 쑥으로 인형을 만들어 문에 걸던 풍습, 쑥으로 물들인 천의 색.
**쑥은 먹는 것이자 물들이는 것이었다.**

**기대효과**: 채취 적기의 개념을 체득한다 · 신화를 식물 특성과 연결해 해석할 수 있다

### 🌳 모듈 3 — 가시 돋친 봄맛 (두릅·엄나무순)

| | |
|---|---|
| **시기** | 4월 |
| **메뉴** | 두릅 초회 · 두릅전 |
| **난이도** | ⭐ 쉬움 · 35분 |

**추천 이유**
데치기만 하면 되는 단순한 조리라 **재료 자체의 맛에 집중**할 수 있다.
비싼 재료이므로 소량으로 하되, 값이 왜 비싼지를 생태로 설명한다.

**🏛 문화해설 — 목두채(木頭菜), 선비의 봄맛**
두릅의 한자 이름은 나무 머리 나물이다. 나무 끝에서 딱 한 번 나오는 순을 먹는다.
조선 문인들의 시에 봄의 전령으로 자주 등장한다.

**🌿 생태해설 — 가시는 왜 있나**
두릅나무와 엄나무는 줄기에 가시가 빽빽하다.

- 새순은 식물에게 **가장 소중한 자산**이다. 그해 광합성의 시작점이기 때문
- 초식동물에게 먹히면 그해 성장이 통째로 무너진다
- **가시는 그것을 지키려는 투자**다
- 위쪽 가지로 갈수록 가시가 줄어드는 나무가 많다 — 초식동물이 못 닿는 높이이기 때문

> "우리는 지금 나무가 가시로 지키던 것을 뺏어 먹는 겁니다. 그래서 비싸요."

**기대효과**: 식물의 방어 전략을 설명할 수 있다 · 가격과 생태를 연결해 이해한다

### 🥒 모듈 4 — 기다림의 맛 (매실·오이)

| | |
|---|---|
| **시기** | 5월 말 ~ 6월 |
| **메뉴** | 오이소박이 · 매실청 담그기 |
| **난이도** | ⭐⭐ 보통 · 60분 |

**추천 이유**
결과물을 **그날 못 먹는** 유일한 회차다. 매실청은 100일, 오이소박이는 하루가 필요하다.
**기다림 자체를 배우는 시간**으로 설계했다.

**💭 철학 — 발효, 시간을 재료로 쓰는 기술**
한국 음식의 근간은 발효다. 발효는 **시간을 조리 도구로 쓰는 유일한 방법**이다.

> 불은 몇 분, 칼은 몇 초. 그런데 발효는 몇 달이 걸린다.
> 조상들은 **기다릴 줄 아는 것을 기술로 여겼다.**

**🌿 생태해설 — 덩굴손, 붙잡는 식물**
오이는 덩굴식물이다. 스스로 서지 못해 **덩굴손으로 무언가를 붙잡고 올라간다.**

- 덩굴손은 잎이나 줄기가 변형된 기관이다
- 접촉을 감지하면 그 방향으로 감긴다 (접촉굴성)
- 중간이 스프링처럼 꼬여 있어 **바람에 당겨져도 끊어지지 않는다**
- **관찰 활동**: 오이 덩굴손 실물을 가져와 꼬임 방향이 중간에서 바뀌는 것을 찾게 한다

> "스스로 못 서는 대신 남을 붙잡고 올라가는 전략입니다. 대신 줄기에 힘을 안 쓰니까
> 그 힘을 열매에 몰아줄 수 있어요."

**기대효과**: 발효의 원리를 이해한다 · 100일 뒤 다시 만나는 경험을 한다 · 덩굴 구조를 관찰할 수 있다

### 🥔 모듈 5 — 땅속의 저장고 (감자·애호박)

| | |
|---|---|
| **시기** | 6월 ~ 7월 |
| **메뉴** | 감자옹심이 · 애호박 새우젓볶음 |
| **난이도** | ⭐⭐⭐ 어려움 · 70분 |

**추천 이유**
햇감자가 나오는 시기다. **가격이 1년 중 가장 낮은 구간**이라 12인 이상 회차에 적합하다.

**🏛 문화해설 — 구황작물의 도착**
감자는 19세기 초 조선에 들어왔다. 흉년에 사람을 살린 작물이라 **구황작물**로 불렸다.

> 새로운 작물 하나가 들어오면 그 지역의 인구와 식생활이 바뀐다.
> **음식의 역사는 곧 생존의 역사다.**

**🌿 생태해설 — 감자는 뿌리가 아니다**
이 회차의 핵심 해설이다.

| | 감자 | 고구마 |
|---|---|---|
| 정체 | **덩이줄기** (땅속줄기가 부푼 것) | **덩이뿌리** (뿌리가 부푼 것) |
| 증거 | **눈(싹눈)이 있다** — 줄기에만 눈이 있다 | 눈이 없다. 양 끝이 다르게 생겼다 |
| 번식 | 잘라 심으면 싹이 난다 | 순을 내어 심는다 |

- **관찰 활동**: 감자의 '눈'을 세어보게 한다. 그리고 고구마에는 눈이 없음을 확인시킨다
- 감자 싹의 독성(솔라닌) — **초록으로 변한 부분은 도려낸다**. 안전 교육과 자연스럽게 연결

> "눈이 있으면 줄기입니다. 이것 하나만 기억하셔도 오늘 수업 값은 하신 겁니다."

**⚠ 안전** 강판 사용. 손가락 보호대 착용, 마지막 조각은 갈지 않는다.

**기대효과**: 덩이줄기와 덩이뿌리를 구분할 수 있다 · 감자 독성 부위를 안다 · 구황작물의 역사적 의미를 이해한다

> "인류가 공장에서 질소비료를 만든 게 100여 년 전입니다.

- **관찰 활동**: 뿌리혹이 달린 콩 뿌리 실물(또는 사진)을 보여준다. 혹을 갈라보면 붉은빛이 돈다

**🏛 문화 곁가지**

**한 작물이 이렇게 많은 음식으로 갈라지는 사례는 드물다.**

**기대효과**: 질소고정의 원리를 설명할 수 있다 · 돌려짓기의 이유를 안다 · 콩 가공식품의 계보를 그릴 수 있다

- 팥 역시 콩과 식물이라 **뿌리혹박테리아와 공생**한다
- 새알심(찹쌀)과 팥을 함께 먹는 것은 **곡물의 부족한 아미노산을 콩류가 보완**하는 조합이다
- 조상들은 영양학을 몰랐지만 **경험으로 이 조합에 도달했다**

**💭 마무리 철학 — 동지, 가장 어두운 날이 곧 전환점**
동지는 밤이 가장 긴 날이다. **그리고 그 다음 날부터 낮이 길어진다.**

> 옛사람들은 동지를 '작은 설'이라 불렀다.
> 가장 어두운 지점에서 이미 반대 방향이 시작된다는 것 — **절기가 가르치는 가장 큰 이야기**다.

**기대효과**: 절기 음식의 의미를 안다 · 색채의 문화적 상징을 이해한다 · 과정 전체를 계절 순환으로 정리한다

## 부록 C. 사실 확인 메모

이야기를 전할 때 **확인된 사실**과 **전해오는 이야기**를 구분해 말한다.

| 내용 | 성격 |
|---|---|
| 김장문화 유네스코 인류무형문화유산 등재 (2013) | **확인된 사실** |
| 고구마 조선 전래 (18세기 후반, 통신사 조엄) | **문헌 기록** |
| 감자 뿌리혹박테리아 질소고정 | **확인된 과학** |
| 무화과 은두화서·무화과말벌 공생 | **확인된 과학** (재배종은 대부분 단위결과) |
| 시금치 저온 시 당 축적 | **확인된 과학** |
| 단군신화의 마늘이 달래·산마늘이었을 가능성 | **학계의 견해 중 하나** — 단정하지 않는다 |
| 동지 팥죽과 공공씨 아들 이야기 | **전해오는 설화** (『형초세시기』) |
| "집 나간 며느리도 돌아온다" | **속담** — 사실이 아니라 표현 |

> 해설자가 이 구분을 지키면 **신뢰가 쌓인다.**
> "그건 전해오는 이야기고요, 확인된 건 이겁니다" — 이 한마디가 해설의 격을 만든다.
