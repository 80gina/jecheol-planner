## 7. 구술 대비 — 질문 ↔ 답변 위치

| 질문 | 위치 | 한 줄 답변 |
|------|------|-----------|
| 왜 이 데이터인가 | 결과보고서 Ⅰ-2 | 요리교실 재료비가 매번 어긋나서 |
| 왜 이 9품목인가 | Ⅳ장 | 짝을 지어 골랐다 — 정반대·같이가는·닮은 짝 + 대조군 |
| 결측치를 어떻게 처리했나 | Ⅴ장 | 연속 3일 이하만 보간. 주말은 결측이 아니다 |
| 왜 평균이 아니라 중앙값인가 | Ⅴ장 | 평균은 튄 값에 끌려가서 이상치를 못 잡는다 |
| 트렌드·계절성·노이즈란 | Ⅶ장 | 긴 흐름 / 매년 반복 / 설명 안 되는 나머지 |
| 왜 라이브러리를 안 썼나 | Ⅶ장 | 부르면 "어떻게"에 답할 수 없다 |
| 이동평균을 왜 두 개 | Ⅷ장 | 갈라지는 지점이 방향 전환 신호 |
| 계절 지수를 왜 만들었나 | Ⅷ장 | 단위가 다른 품목을 나란히 비교하려고 |
| AI 결과를 어떻게 검증했나 | Ⅸ장 | 정답을 심은 가짜 데이터로. 오류 2건 잡음 |
| 무엇을 본인이 판단했나 | Ⅹ장 | 주제·품목·정제기준·가설·한계 |
| 상관계수가 높으면 원인인가 | Ⅵ장 | 아니다. 양파 r=−0.79로 가장 강한데 진폭 32.6p(하위권), 배추는 진폭 61.1p인데 r=−0.04 |
| 왜 예측을 안 했나 | Ⅹ장 | 1년(1주기) 표본으로는 설명할 가정 자체가 부실해진다 |
| 왜 연간이 아니라 주간 주기로 분해했나 | Ⅶ장 | 1년 자료에 1년 창은 두 번 이상 못 채운다. 추세가 통째로 빈다 |
| 2년을 요청했는데 왜 1년인가 | Ⅰ-1, XI장 | KAMIS 가 최근 1년만 제공. probe_history.py 로 확인. 범위 밖은 HTTP 500 |

## 8. 마지막 확인 명령어

제출 직전에 이 순서로 확인합니다.

```powershell
git status
```

> `nothing to commit, working tree clean` 이어야 합니다.

```powershell
git log --oneline
```

> 커밋이 5개 안팎 보여야 합니다.

```powershell
Get-ChildItem images
```

> PNG 6장이 있어야 합니다.

```powershell
Select-String -Path .gitignore -Pattern "^\.env$"
```

> `.env` 가 걸려 있어야 합니다. **인증키가 GitHub 에 올라가면 안 됩니다.**
